# Memory Merge v0.1.0-alpha.1

> First public-delivery candidate. Pre-release, not production-stable.

## Added
- Transactional SQLite storage with retryable Markdown mirrors.
- Automatic candidates, user-requested memories, human review, six categories, project scopes and event idempotency.
- Native stdio integration using the official MCP SDK and a local read-only mind graph.
- Offline lexical retrieval by default, optional Embedding/Judge adapters, and cited RAG evidence packages.
- Backup, mirror rebuilding and 15 automated tests.

## Release preparation and privacy
- Bilingual README with reference projects, GitHub repositories and public author/organization credits at the beginning.
- Rewritten public research and architecture documentation; private information, machine-specific absolute paths, original conversations, databases, environments, logs and research snapshots excluded.
- Source ZIP, per-file manifest and SHA-256 checksum provided.

## Known limitations
- Real-model quality, all MCP clients and cross-platform operation are not comprehensively verified.
- Clients generate RAG answers; default lexical retrieval is not semantic search.
- No multi-tenant authentication, secure erasure, automatic host hooks or automatic merging.
- An open-source license for the original work remains for the rights holder to select.

## Release scope
This is a local release bundle, not a GitHub upload. Mark the online release as Pre-release when publishing.
